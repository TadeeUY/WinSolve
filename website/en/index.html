What it does

Everything is explained before you run it.

Risky actions create a restore point first. Anything you delete by hand goes to the Recycle Bin.

One-click optimization
Light, Balanced or Maximum, for desktop or laptop. The plan adapts to what it finds: SSD or HDD, RAM, GPU vendor, battery. A restore point is created first and you get a before and after comparison.
Cleanup and repair
Temp files, Windows Update cache and leftovers. DISM and SFC, CHKDSK, and resets for Windows Update, the network stack, the Store and the Start menu. It never touches your documents or Windows folders.
Disk space
A WizTree-style map of what fills the disk, a file type breakdown, big forgotten files and a duplicate finder.
Disk health
S.M.A.R.T. in plain words: temperature, wear, power-on hours. Per-volume repair with advice based on the drive’s health, and alerts when a drive gets worse or an SSD is running out of life.
Drivers
Detects NVIDIA, AMD and Intel graphics. Clean install of the latest NVIDIA driver (old display drivers removed first) or AMD Adrenalin, with a backup of the current one. It can also remove the old driver copies Windows keeps.
Tweaks
Essential and advanced tweaks, each with Run and Undo, plus DNS presets, Windows Update policy and optional features such as WSL, Hyper-V or Sandbox.
Toolbox
Disk speed test, locked file finder, secure delete, network test, saved Wi-Fi passwords, hosts file editor, battery report, restore points and a PC report as PDF without serial numbers or keys.
Internet
Checks the router, the Internet and the DNS and says where the problem is. Lists the devices on your network, makes a Wi-Fi QR code and recommends the least crowded Wi-Fi channel.
And more
Startup apps, uninstall with leftovers, activation status, a live monitor, background alerts when Windows reports errors, scheduled cleanup, and Ctrl + K to find any page or tool.
Safety

How it avoids breaking things

Saves before it changes

A restore point, a copy of your current driver and a backup of every tweak. If something goes wrong, it goes back.

Only your account

It works with the signed-in user’s files, apps and settings, never with other accounts on the PC.

Updates stay out of the way

Updates are checked against their SHA-256 and wait until you are not using the app.

Tested on real Windows

Every feature is tested automatically on a real Windows machine before each version is released.

FAQ

Questions

Is it free?

Yes, completely. There is no paid version, no ads and no account. The code is on GitHub.

Why does Windows say "Windows protected your PC"?

The installer has no digital signature yet, so SmartScreen doesn't know the file. Click More info → Run anyway. You can check the file is the original with its SHA-256, shown on the download page.

Can it break my Windows?

It is built not to: before big changes it creates a restore point, keeps copies of what it changes and never deletes your personal files or system folders. Anything you delete by hand goes to the Recycle Bin.

Does it update itself?

It tells you when there is a new version. If you turn on automatic updates, it installs itself without opening windows and without cutting off anything you are doing.

Is there a portable version?

Yes: WinSolve-Portable.exe runs without installing, for example from a USB stick.
