Install

  1. Open WinSolveSetup.exe.
  2. If "Windows protected your PC" appears, click More info and then Run anyway. It shows because the installer has no digital signature yet.
  3. Choose All users (recommended) or Only me, the language and whether you want a desktop shortcut.
  4. Click Install. If your PC is missing .NET 8, setup downloads and installs it by itself.

WinSolve asks for administrator rights when it opens, because many repairs need them. It only changes your account and the system, never other accounts.

To uninstall: Windows Settings → Apps → WinSolve → Uninstall.

Getting started

When you open WinSolve, Home checks the PC and shows a health score with what is worth a look. From there:

  • One-click optimization: pick the kind of PC (desktop or laptop) and the level (Light, Balanced or Maximum performance). It creates a restore point before changing anything.
  • Search (Ctrl + K): find any tool by typing its name, for example "safe mode".
  • Icon next to the clock: WinSolve can stay in the notification area to warn you about problems (a failing disk, high temperature).

Cleanup

Cleanup & repair removes temp files, browser cache and Windows Update leftovers. Temp files are only removed when they are over a day old, and your personal folders and Windows folders are never touched. Disk space shows a map of what takes the most room, big files you haven't opened in a year and duplicates. What you delete from there goes to the Recycle Bin.

Disks

In Hardware → Disks you see each disk's health (S.M.A.R.T.) in plain words, and for every drive you have:

  • Check: looks for errors without changing anything.
  • Fix file system errors: repairs what it finds.
  • Scan & repair bad sectors: reads the whole disk, recovers what it can and isolates the bad areas. It can take hours.
  • Last check result: what the last check at Windows startup found.

If it is the Windows drive, or Windows won't hand it over ("Access denied"), the check is scheduled for the next restart: you will see a black screen checking the disk before you sign in. Don't turn the PC off meanwhile. If you change your mind, click Cancel scheduled check.

Drivers

WinSolve detects your graphics card and can do a clean install of the NVIDIA or AMD driver: it saves your current driver and puts it back if anything goes wrong. It also removes old drivers left after updates (never the ones in use) and backs up your drivers.

Safe Mode

In Toolbox → Safe Mode choose Safe Mode or Safe Mode with Networking and click Restart in Safe Mode.

  • Only the next start is in Safe Mode; the one after is normal again, even if you don't open WinSolve.
  • If BitLocker is on, it is paused for that one restart only.
  • If your PIN or fingerprint doesn't work in Safe Mode, sign in with your account password.
  • From Safe Mode, Restart normally also turns off a Safe Mode left on with msconfig.
  • Advanced startup restarts into the blue Windows recovery menu.

Toolbox

  • Disk speed test: sequential and random read and write, like CrystalDiskMark.
  • Locked file finder: which program is using a file, close it or delete the file at restart.
  • Secure delete: overwrites files before deleting them.
  • Network test and saved Wi-Fi passwords.
  • Hosts file editor, with an automatic backup.
  • Battery report: how much capacity it has lost and how long it lasts.
  • Right-click menu cleanup, restore points and a PC report as a PDF.

Updates

WinSolve looks for new versions every time it opens and every hour. When there is one, a bar with Update now appears at the top: it takes less than a minute and keeps your settings. Every update is downloaded only from GitHub and checked against its SHA-256 before installing.

If you turn on Settings → Install updates automatically, it installs by itself, but never interrupts you:

  • It waits until no task, tool or WinSolve window is open.
  • It doesn't install during full-screen games, videos or presentations.
  • If WinSolve is next to the clock, it updates silently, without opening windows, and goes back there. If its window is open, it waits until you have been away from the PC for 10 minutes.
  • If something fails, it reopens the previous version, which stays intact.

Safety and privacy

  • No ads, no accounts and no tracking. It only goes online to check for updates, download drivers you ask for and run the network test.
  • Before big changes it creates a restore point and keeps a copy of every setting it changes.
  • It works only with the signed-in user; it doesn't touch other accounts.
  • The code is open: github.com/TadeeUY/WinSolve.

Releases

The latest releases. What is new in each one shows in WinSolve under What's new after updating.

Help

Something not working? In WinSolve, Settings → Create bug report saves a file on your desktop with the logs (no personal data). Attach it to an issue on GitHub and explain what happened.
