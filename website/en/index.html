Features

Everything your PC needs, in one place.

Instead of ten different programs, one app that tells you what each thing does before doing it.

One-click optimization

Pick Light, Balanced or Maximum performance: it cleans up, tunes power and applies the recommended tweaks. It creates a restore point first.

Safe cleanup

Temp files, cache and update leftovers. It never touches your documents or Windows folders.

Drivers

Clean NVIDIA and AMD installs with a backup of your current driver, and cleanup of old drivers.

Disk space

A visual map of what fills your disk, big forgotten files and duplicates. What you delete goes to the Recycle Bin.

Disk health and repair

S.M.A.R.T. in plain words, file system repair and bad sector scans, even when they have to run at restart.

> Checking E: …
✓ File system has no errors
✓ 0 KB in bad sectors
✓ Reallocated: 0 · Pending: 0

Safe Mode without getting stuck

Restarts in Safe Mode (with or without internet) just once. With BitLocker on, it pauses it for that restart so you are not asked for the key.

> Preparing a one-time start…
✓ Temporary boot entry created
✓ BitLocker paused for 1 restart
✓ The next start is normal again

PC report

A PDF with your PC's score, every part and the upgrade that would help most. No serial numbers or keys.

Live monitor

Processor, memory, disk and temperatures, with alerts when something overheats or fails.

Toolbox

Disk speed, locked files, saved Wi-Fi passwords, hosts file, battery, restore points and more.

Built not to break anything

Careful with your PC, on purpose.

Every feature is tested automatically on a real Windows machine before each version is released.

Saves before it changes

A restore point, a copy of your current driver and a backup of every tweak. If something goes wrong, it goes back.

Only your account

It works with your user only: it never touches the files or settings of other accounts on the PC.

Updates without bothering you

Updates are checked against their SHA-256 and never cut off what you are doing: they wait until you are not using it.

FAQ

What everyone asks.

Is it free?

Yes, completely. There is no paid version, no ads and no account. The code is on GitHub.

Why does Windows say "Windows protected your PC"?

The installer has no digital signature yet, so SmartScreen doesn't know the file. Click More info → Run anyway. You can check the file is the original with its SHA-256, shown on the download page.

Can it break my Windows?

It is built not to: before big changes it creates a restore point, keeps copies of what it changes and never deletes your personal files or system folders. Anything you delete by hand goes to the Recycle Bin.

Does it update itself?

It tells you when there is a new version. If you turn on automatic updates, it installs itself without opening windows and without cutting off anything you are doing.

Is there a portable version?

Yes: WinSolve-Portable.exe runs without installing, for example from a USB stick.
